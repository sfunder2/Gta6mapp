# Leonida Haritası

GTA VI için hayran yapımı, etkileşimli Leonida haritası. Tek bir statik `index.html` dosyası; derleme gerekmez.

- Elle çizilmiş temsili taban harita (SVG), Leaflet ile
- Kategori filtreleri ve arama
- Haritaya kendi işaretini ekleme (tarayıcıda saklanır), JSON içe/dışa aktarma

Bölge adları Rockstar Games'in resmi fragmanlarından ve sitesinden alınmıştır; konumlar yaklaşıktır. Başka harita sitelerinin görselleri, işaret veritabanları veya metinleri kullanılmamıştır.

Resmi değildir; Rockstar Games veya Take-Two ile bağlantısı yoktur.
